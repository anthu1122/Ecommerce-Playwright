# Bug Report Template

Copy file này thành `docs/bugs/BUG-001.md` cho mỗi bug tìm được. Đính kèm ảnh/video vào thư mục `docs/bugs/images/`.

---

## BUG-XXX: [Module] Tiêu đề ngắn gọn, nêu rõ lỗi

| Trường | Giá trị |
|--------|---------|
| **Ngày phát hiện** | YYYY-MM-DD |
| **Người báo** | Tên bạn |
| **Môi trường** | Website / URL, trình duyệt + phiên bản, hệ điều hành |
| **Tài khoản dùng** | Ví dụ: `problem_user` |
| **Mức độ nghiêm trọng (Severity)** | Critical / High / Medium / Low |
| **Độ ưu tiên (Priority)** | P1 / P2 / P3 |
| **Trạng thái** | New / Confirmed / Fixed / Closed |
| **Test case liên quan** | Ví dụ: TC_CART_02 |

### Các bước tái hiện
1. Mở ...
2. Đăng nhập bằng ...
3. Thực hiện ...

### Kết quả mong đợi
Mô tả hệ thống phải hoạt động thế nào.

### Kết quả thực tế
Mô tả chính xác điều đã xảy ra.

### Tần suất
Luôn xảy ra / Thỉnh thoảng (x/10 lần)

### Đính kèm
- Ảnh chụp màn hình: `images/BUG-XXX.png`
- Video / log (nếu có)

### Ghi chú
Workaround, nghi ngờ nguyên nhân, ảnh hưởng tới các chức năng khác...

## Mẹo viết bug report tốt

- Tiêu đề trả lời được 3 câu hỏi: **ở đâu, làm gì, sai thế nào**.
- Mỗi bug một report, không gộp nhiều lỗi.
- Bước tái hiện đủ để người khác làm theo mà không cần hỏi lại.
- Tách rõ **mong đợi** và **thực tế**, không đưa phỏng đoán vào phần thực tế.
- Ghi rõ Severity (mức ảnh hưởng) khác với Priority (mức cần sửa sớm).
